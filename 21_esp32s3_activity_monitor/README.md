# 21 · 基于 ESP32-S3 的智能人员活动状态监测系统

> **难度** ★★★★　|　**主控** ESP32-S3　|　**状态** ⬜ 未开始

检测人员活动并统计次数与时段，长时间无活动或夜间异常活动时提醒，记录可在 Web 查看。

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| 红外检测模块 | 人员活动检测 |
| 光敏电阻模块 | 光照 / 昼夜判断 |
| DHT11 | 环境温湿度 |
| 0.96" OLED | 状态与统计显示 |
| 蜂鸣器 | 异常提醒 |

## 功能需求

- [ ] 检测人员活动
- [ ] 统计活动次数
- [ ] 记录活动时间
- [ ] 判断长时间未检测到活动
- [ ] 夜间活动提醒
- [ ] Web 查看活动记录

## 技术要点

- 时间窗口统计
- 活动频率分析
- 异常时段识别

## 研究内容

- 时间窗口统计
- 活动频率分析
- 异常时段识别

## 备注

现有红外避障模块主要用于物体检测，不能直接准确识别人体；若要可靠监测，建议增加 PIR 人体红外传感器。
