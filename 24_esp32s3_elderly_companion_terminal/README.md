# 24 · 基于 ESP32-S3 的智能养老陪护交互终端

> **难度** ★★★★★　|　**主控** ESP32-S3　|　**状态** ⬜ 未开始

OLED 交互界面 + 舵机动作 + 温湿度/声音检测，做面向老人的陪护交互终端与提醒设备。

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| 0.96" OLED | 交互界面 |
| SG90 舵机 | 头部 / 指示机构动作 |
| 麦克风模块 | 声音检测 |
| 蜂鸣器 | 语音提示 / 提醒 |
| DHT11 | 温湿度监测 |
| 旋转编码器 | 菜单操作 |

## 功能需求

- [ ] OLED 显示交互界面
- [ ] 舵机控制头部或指示机构
- [ ] 温湿度监测
- [ ] 声音检测
- [ ] 语音交互扩展
- [ ] 老人提醒功能
- [ ] 网络消息接收

## 技术要点

- 嵌入式人机交互界面设计
- 状态机控制多设备协同
- 多设备通信（消息接收与响应）

## 创新点

- 嵌入式人机交互
- 状态机控制
- 多设备通信

## 备注

现有麦克风模块未必能满足语音识别要求；若要做真正的语音助手，建议增加支持语音采集的麦克风及语音识别服务。
