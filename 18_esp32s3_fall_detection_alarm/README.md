# 18 · 基于 MPU6050 的智能跌倒检测与报警系统

> **难度** ★★★★　|　**主控** ESP32-S3　|　**状态** ⬜ 未开始

采集三轴加速度与角速度，设计跌倒识别算法，判定疑似跌倒后本地报警并上传事件。

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| MPU6050 | 六轴加速度 / 角速度（I2C） |
| 0.96" OLED | 实时姿态与状态显示 |
| 蜂鸣器 | 本地声光报警 |
| W25QXX | 跌倒记录存储 |

## 功能需求

- [ ] 实时采集三轴加速度和角速度
- [ ] 计算运动状态及姿态变化
- [ ] 设计跌倒识别算法
- [ ] 判断疑似跌倒事件
- [ ] 本地声光报警
- [ ] Wi-Fi 上传异常事件
- [ ] 保存跌倒记录

## 技术要点

- 加速度合成与姿态角解算
- 滑动窗口滤波与特征提取
- 多阈值联合判断，区分跌倒与日常活动

## 研究内容

- 加速度合成计算
- 姿态角解算
- 滑动窗口滤波
- 多阈值联合判断
- 跌倒与日常活动的区分
