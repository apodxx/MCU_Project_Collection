# 05 · 基于 STM32 的智能防盗报警系统

> **难度** ★　|　**主控** STM32F103C8T6　|　**状态** ⬜ 未开始

红外检测到人员进入即触发声光报警，触摸输入解除，OLED 显示布防/撤防状态并统计报警次数。

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| 红外避障模块 | 检测人员进入（近距） |
| 触摸模块 | 撤防 / 解除报警 |
| 蜂鸣器 | 声光报警 |
| 0.96" OLED | 显示布防状态与报警次数 |

## 功能需求

- [ ] 检测人员进入
- [ ] 触发声光报警
- [ ] 触摸输入解除报警
- [ ] 显示系统布防和撤防状态
- [ ] 统计报警次数

## 技术要点

- 布防 / 撤防 / 报警 状态机
- 触发消抖与防误报
- 报警计数与事件显示

## 拓展方向

- 改用 PIR 人体红外传感器，提高人员检测可靠性；增加 GSM/Wi-Fi 远程通知

## 备注

红外避障模块更适合近距物体检测，若要可靠识别人体，建议增加 PIR 人体红外传感器。
