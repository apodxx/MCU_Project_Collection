# 19 · 基于 STM32 的智能设备振动监测与故障预警系统

> **难度** ★★★★　|　**主控** STM32F103C8T6　|　**状态** ⬜ 未开始

采集设备振动数据，计算幅值、RMS 与频谱特征，识别异常振动并预警，历史数据本地保存。

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| MPU6050 | 振动采集（I2C） |
| 0.96" OLED | 振动波形 / 指标显示 |
| 蜂鸣器 | 异常报警 |
| W25QXX | 振动历史数据存储 |

## 功能需求

- [ ] 采集设备振动数据
- [ ] 计算振动幅值
- [ ] 统计振动变化
- [ ] 识别异常振动
- [ ] 保存振动历史数据
- [ ] 异常状态报警

## 技术要点

- 数字滤波（低通 / 滑动平均）
- RMS 与峰值检测
- FFT 频谱分析（CMSIS-DSP）

## 研究内容

- 数字滤波
- 均方根 RMS
- 峰值检测
- FFT 频谱分析

## 备注

可用小电机模拟设备的正常运行与异常振动，便于采集对比数据。
