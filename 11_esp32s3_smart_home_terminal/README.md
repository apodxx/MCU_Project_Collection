# 11 · 基于 ESP32-S3 的智能家居控制终端

> **难度** ★★　|　**主控** ESP32-S3　|　**状态** ⬜ 未开始

OLED 菜单 + 触摸/旋钮操作，控制灯光家电、监测温湿度，并支持 Wi-Fi 远程控制与状态反馈。

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| 继电器模块 | 灯光 / 家电控制 |
| 触摸模块 | 触摸开关 |
| 旋转编码器 | 菜单与调节 |
| 0.96" OLED | 菜单交互界面 |
| DHT11 | 温湿度采集 |

## 功能需求

- [ ] 智能灯光控制
- [ ] 温湿度监测
- [ ] 触摸开关
- [ ] OLED 菜单交互
- [ ] Wi-Fi 远程控制
- [ ] 设备状态反馈

## 技术要点

- 菜单状态机与焦点管理
- Web / App 控制接口与本地操作同步
- 设备状态回读与显示刷新

## 拓展方向

- 接入 MQTT，接入 Home Assistant 或自建平台
