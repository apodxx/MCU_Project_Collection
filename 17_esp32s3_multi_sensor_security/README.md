# 17 · 基于 ESP32-S3 的多传感器智能安防监测系统

> **难度** ★★★　|　**主控** ESP32-S3　|　**状态** ⬜ 未开始

入侵、气体、声音三路联合检测，多条件触发报警，Web 实时监控并记录报警事件。

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| 红外避障模块 | 人员入侵检测 |
| MQ 气体传感器 | 环境气体检测 |
| 麦克风模块 | 声音异常检测 |
| 继电器模块 | 联动输出（警灯 / 门锁） |
| 0.96" OLED | 本地显示 |
| 蜂鸣器 | 现场报警 |

## 功能需求

- [ ] 人员入侵检测
- [ ] 环境气体检测
- [ ] 声音异常检测
- [ ] 多条件报警
- [ ] Web 实时监控
- [ ] 报警事件记录

## 技术要点

- 多条件与 / 或逻辑判定
- 事件记录与查询接口
- Web 端实时状态推送

## 拓展方向

- 增加摄像头或门磁，形成更完整的安防方案
