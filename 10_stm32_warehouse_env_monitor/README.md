# 10 · 基于 STM32 的智能仓储环境监测系统

> **难度** ★★　|　**主控** STM32F103C8T6　|　**状态** ⬜ 未开始

仓储温湿度与气体异常监测，超限报警，历史数据写入 W25QXX，OLED 显示设备运行状态。

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| DHT11 | 温湿度采集 |
| MQ 气体传感器 | 气体异常检测 |
| 光敏电阻模块 | 光照监测 |
| 0.96" OLED | 状态显示 |
| 蜂鸣器 | 超限报警 |
| W25QXX | 历史数据存储（SPI） |

## 功能需求

- [ ] 仓储环境监测
- [ ] 气体异常检测
- [ ] 温湿度超限报警
- [ ] 历史数据存储
- [ ] 设备运行状态显示

## 技术要点

- W25QXX SPI 读写与扇区管理
- 定时记录 + 循环覆盖策略
- 上电恢复与数据完整性校验

## 拓展方向

- 增加 RTC 时间戳与掉电检测，形成完整的数据记录仪
