# 07 · 基于 STM32 的智能宿舍环境监测系统

> **难度** ★★　|　**主控** STM32F103C8T6　|　**状态** ⬜ 未开始

宿舍温湿度、烟雾气体、光照一体化监测，环境异常报警，光照不足自动照明，多页面显示。

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| DHT11 | 温湿度采集 |
| MQ 气体传感器 | 烟雾 / 可燃气体检测 |
| 光敏电阻模块 | 光照检测 |
| 0.96" OLED | 多页面显示 |
| 蜂鸣器 | 异常报警 |
| 继电器模块 | 自动照明 |

## 功能需求

- [ ] 温湿度监测
- [ ] 烟雾及可燃气体相关检测
- [ ] 光照检测
- [ ] 自动照明
- [ ] 环境异常报警
- [ ] 多页面显示

## 技术要点

- 多传感器轮询与数据滤波
- 分级报警（提示 / 严重）
- 继电器联动与迟滞控制

## 拓展方向

- 接入 Wi-Fi 上传数据，做宿舍环境云平台

## 备注

MQ 系列气体传感器需要预热，阈值需在实际环境中标定。
