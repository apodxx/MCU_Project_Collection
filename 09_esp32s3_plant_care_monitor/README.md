# 09 · 基于 ESP32-S3 的智能植物养护监测系统

> **难度** ★★　|　**主控** ESP32-S3　|　**状态** ⬜ 未开始

监测植物生长环境的温湿度与光照，按阈值自动补光，数据经 Wi-Fi 远程查看。

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| DHT11 | 温湿度采集 |
| 光敏电阻模块 | 光照检测 |
| 继电器模块 | 控制补光灯 |
| 0.96" OLED | 本地显示 |
| 蜂鸣器 | 阈值提醒 |

## 功能需求

- [ ] 监测植物生长环境温湿度
- [ ] 检测环境光照
- [ ] 设置适宜生长阈值
- [ ] 自动控制补光设备
- [ ] Wi-Fi 远程查看数据

## 技术要点

- ESP32-S3 Wi-Fi STA 联网与数据上报
- 光照阈值控制补光（含迟滞）
- 本地显示 + 远程页面双通道

## 拓展方向

- 增加土壤湿度传感器 + 水泵，实现自动浇水闭环

## 备注

目前没有确认土壤湿度传感器；若要真正实现自动浇水，需要额外购买土壤湿度模块和水泵。
