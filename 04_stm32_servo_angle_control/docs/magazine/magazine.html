一个迷你道闸的拆解

红外一响栏杆抬起

单片机从0到100 · 项目 0401 / 05
自动闸门论述 / 效率与决定权

车不等人，
人也得放心

道闸有个天生的矛盾：车流要的是效率，现场要的是可控。全自动在无人值守时最省事，但有人值守的岗亭里，管理员往往希望“先看一眼，再决定放不放行”。这不是技术落后，而是场景不同。

所以这个项目把选择交回给人：编码器转一格，模式在自动和手动之间切换。同一套硬件、同一段固件，早上车流高峰可以无人值守，傍晚有活动时可以人工确认。

自动模式：把判断交给探头

红外避障模块装在闸机前方十几厘米，车头压过来，OUT 从高电平变成低电平。固件认定“有车”，立刻把舵机推到 90°，栏杆竖起。车开走、探头前空出来，再等 3 秒落杆——留出车尾通过的时间。

同一套硬件，两种脾气

红外、舵机、蜂鸣器一个没换，变的是判断顺序：自动模式“先执行，再报告”，手动模式“先报告，等指令”。一个模式变量，决定了同一辆车会遇到什么。

手动模式：把决定留给人

切到手动，探头不再直接开闸，而是先“提醒”：蜂鸣器响 300 毫秒，屏幕上的状态开始闪「等待」。管理员看一眼情况，按一下触摸模块，栏杆才抬起；再按一下，落杆。

这样探头只负责“报告”，不负责“执行”。同一个红外信号，在不同模式下的含义完全不同——这正是模式切换存在的意义。

消抖，比灵敏度更重要

红外输出是开关量，树叶、飞虫、反光都会让它抖一下。固件要求电平稳定 50 毫秒才认，避免栏杆跟着抖动反复抬落。手动模式下更严格：只在“无车 → 有车”的上升沿提醒一次，不会一直响。

手动也不是“关掉自动”：探头仍在工作，只是它的输出从命令降级成提醒。切模式时如果探头前正好有车，蜂鸣器会立刻响一声——它在补报刚才没来得及说的那句话。

经验是留给下一次的

模式切换、消抖、延时，这三个动作都不复杂，却正好对应真实设备里最难处理的三件事：谁负责判断、信号可不可信、动作什么时候发生。

自动闸门 · 项目 0402 / 05
自动闸门展开 / 自动模式的一次通行
从检测到落杆

一次通行，
只有三秒

车压到红外，抬杆；车走后三秒，落杆。这段流程里，固件要处理三件事：确认“真的有车”、决定“什么时候落杆”、控制“栏杆怎么动”。

第一步，先确认真的有车

红外输出的只是一个高低电平，它分不清车和人。固件先做 50 毫秒消抖：电平连续稳定才承认变化。几行代码，决定了装置是“灵敏”还是“神经质”。

第二步，什么时候落杆

车走就落杆听着合理，实际很危险：车尾还没过完，栏杆已经压下来。固件用 3 秒延时补偿：探头前空出来开始计时，期间再来车就取消倒计时。

这 3 秒写在 board.h 的 APP_AUTO_CLOSE_MS，车长就调大，演示可以调到 1 秒。

第三步，栏杆怎么动

舵机要的是 50Hz 方波：0.5ms 对应 0°，2.5ms 对应 180°，中间线性映射。固件把角度换算成计数器值直接写进寄存器，剩下的交给 TIM2。

目标角度可以一步跳变，输出不会：主循环每 20ms 只走 2°，90° 要约 0.9 秒。栏杆是抬起来的，不是弹起来的。

自动闸门 · 项目 0403 / 05
自动闸门收束 / 人、规则与兜底

手动不是落后，是把决定权留给人

自动解决“没人看着也能跑”，手动解决“有人看着更放心”。两者共用一套执行机构，差别只在谁按下最后那一下。

三个动作，
一条兜底

短按：开闸；再短按：落杆。长按：不管什么状态，立刻强制落杆。

强制落杆放在长按上，是刻意的：不该被误触，需要时必须立刻生效。

把“紧急”留给一个不容易误触的动作

真实道闸都有急停和手动释放。这个迷你版保留了同样的思路：正常操作走短按，紧急动作走长按，800 毫秒才触发，不容易被路过的人碰到。

手动模式检测到车时，屏幕会闪「等待」、蜂鸣器响一声——不是催你，是提醒“探头看见车了”。

一条可以复用的规则

把“感知”和“执行”分开，是这个项目最值得带走的一条经验：红外只负责报告，模式决定谁来拍板。以后加超声波、加第二个探头、接远程开关，都只是在这条链路上加环节。

编辑结语 · 非人物引语

自动让人省心，
手动让人安心；
能随时切换，才是好用。

把逻辑
装进 25KB

整套固件 25.3KB，不到 64KB Flash 的四成。空间不是问题，取舍在于哪些交给硬件定时器，哪些留给软件循环。

引脚用途说明

PWM 与缓动

舵机要 50Hz 方波，脉宽决定角度：CCR = 500 + angle × 2000 / 180（µs）。TIM2 用 72 分频得到 1MHz 计数，周期 20000 就是 20ms。

目标角度可以一步跳变，输出不会：每 20ms 只走 2°，90° 约 0.9 秒。栏杆是抬起来的，不是弹起来的。

完整接线：舵机单独 5V，其余模块 3V3，GND 全部共地
