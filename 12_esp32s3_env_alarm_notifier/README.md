# 12 · 基于 ESP32-S3 的智能环境报警与远程通知系统

> **难度** ★★　|　**主控** ESP32-S3　|　**状态** ⬜ 未开始

多传感器采集与异常识别，按严重程度分级报警，数据经 Wi-Fi 上传，手机或网页查看报警信息。

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| MQ 气体传感器 | 气体异常检测 |
| DHT11 | 温湿度采集 |
| 麦克风模块 | 声音异常检测 |
| 0.96" OLED | 本地状态显示 |
| 蜂鸣器 | 本地声光报警 |

## 功能需求

- [ ] 多传感器数据采集
- [ ] 环境异常识别
- [ ] 分级报警
- [ ] Wi-Fi 数据上传
- [ ] 手机或 Web 端查看报警信息

## 技术要点

- 分级报警策略（提示 / 警告 / 紧急）
- MQTT / HTTP 消息上报
- 断网缓存与重连补发

## 拓展方向

- 接入微信 / 钉钉机器人或短信网关，实现真正的远程通知
