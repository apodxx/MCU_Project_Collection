# 视频简介 · 项目 04 自动闸门

> 用于 B 站 / 抖音 / 小红书发布，直接复制即用。

## B 站版

```
【单片机从0到100】第4期：基于 STM32 的自动闸门控制系统

一块 STM32、一个 SG90 舵机、一个红外、一个触摸，做出三种工作模式：
手动、往复、自动。

▍功能介绍
· 手动模式：目标恒定 90°，上电当前 0°；按一次触摸 → 90°（开闸），再按一次 → 0°（关闸）
· 往复模式：栏杆在 0° 和 180° 之间自动来回，演示和行程测试都方便
· 自动模式：目标恒定 90°；红外检测到东西 → 90°，东西离开 → 0°，按“变化”触发，不反复开关
· 任何模式长按触摸 = 强制关闸回 0°（安全兜底）
· OLED 四行：模式 / 目标 / 当前 / 状态（到位、转动中、有车）
· 50Hz PWM，0.5~2.5ms 对应 0~180°，每 20ms 走 2° 缓动

▍接线方法
舵机 橙线 → PA0（TIM2_CH1）
触摸 OUT → PA3
红外 OUT → PA4
OLED SCL → PB10，SDA → PB11
蜂鸣器 IN → PB5
电源：舵机单独 5V，其余模块 3V3，所有 GND 共地
（详细接线图、逐针说明见项目目录 hardware/）

## 置顶评论

```
本期接线要点：
① 舵机橙色信号线接 PA0，红线接 5V（不是 3.3V），棕线接地
② 触摸 OUT 接 PA3，上电时手别碰触摸板（固件在识别极性）
③ 红外 OUT 接 PA4，检测到东西输出低电平
④ OLED SCL→PB10、SDA→PB11，VCC 接 3V3
⑤ 蜂鸣器 IN 接 PB5
