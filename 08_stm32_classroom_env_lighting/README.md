# 08 · 基于 STM32 的智能教室环境监测与照明控制系统

> **难度** ★★　|　**主控** STM32F103C8T6　|　**状态** ⬜ 未开始

教室温湿度与光照监测，自动照明控制，环境异常提醒，支持手动/自动模式切换。

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| DHT11 | 温湿度采集 |
| 光敏电阻模块 | 光照监测 |
| 继电器模块 | 照明控制 |
| 0.96" OLED | 数据显示 |
| 蜂鸣器 | 异常提醒 |

## 功能需求

- [ ] 教室温湿度监测
- [ ] 环境光照监测
- [ ] 自动照明控制
- [ ] 环境异常提醒
- [ ] 手动与自动模式切换

## 技术要点

- 手动 / 自动模式状态机
- 光照回差控制，避免继电器频繁动作
- 多参数异常判定

## 拓展方向

- 增加人体感应，实现「有人且光照不足」才开灯，节能效果更明显
