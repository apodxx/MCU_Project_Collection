# 15 · 基于 STM32 与 ESP8266 的无线传感器数据采集系统

> **难度** ★★★　|　**主控** STM32F103C8T6 + ESP8266　|　**状态** ⬜ 未开始

STM32 负责采集与本地存储，ESP8266 负责无线上传；断网时缓存，恢复后自动补传。

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| ESP8266 | Wi-Fi 通信（UART / AT 指令） |
| DHT11 | 温湿度采集 |
| MQ 气体传感器 | 气体检测 |
| 0.96" OLED | 本地显示 |
| W25QXX | 断网缓存（SPI） |

## 功能需求

- [ ] STM32 负责传感器采集
- [ ] ESP8266 负责无线通信
- [ ] UART 自定义数据协议
- [ ] 数据上传服务器
- [ ] 本地 Flash 保存数据
- [ ] 网络中断后缓存数据，恢复后补传

## 技术要点

- 帧头 / 长度 / 数据 / 校验的帧格式设计
- 超时重传与断线重连
- 缓存队列与补传顺序保证

## 研究内容

- 主控与通信模块之间的数据协议设计
- 异常处理：丢包、超时、模块掉线
- 断线重连与数据补传策略
