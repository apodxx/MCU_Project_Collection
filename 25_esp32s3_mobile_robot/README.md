# 25 · 基于 ESP32-S3 的智能移动机器人环境感知与交互控制系统

> **难度** ★★★★★　|　**主控** ESP32-S3　|　**状态** ⬜ 未开始

机器人姿态与运动状态监测、轮速计数、前方避障、舵机控制，OLED 显示并支持无线控制。

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| MPU6050 | 运动姿态检测 |
| 红外避障模块 | 前方障碍物检测 |
| 槽型光电传感器 | 轮速 / 转速计数 |
| 0.96" OLED | 状态显示 |
| SG90 舵机 | 转向 / 云台控制 |
| 蜂鸣器 | 运行异常报警 |

## 功能需求

- [ ] 移动机器人状态监测
- [ ] 运动姿态检测
- [ ] 轮速或转速计数
- [ ] 前方障碍物检测
- [ ] 舵机控制
- [ ] OLED 状态显示
- [ ] 无线控制
- [ ] 运行异常报警

## 技术要点

- 运动状态采集与姿态解算
- 轮速计算（脉冲计数 / 定时采样）
- 避障控制与无线控制协议

## 研究内容

- 运动状态采集
- 轮速计算
- 避障控制
- 运动状态反馈
- 无线控制协议

## 备注

需要额外增加电机驱动板与底盘，才能从「感知平台」拓展为可移动机器人。
