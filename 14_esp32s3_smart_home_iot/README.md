# 14 · 基于 ESP32-S3 的智能家居物联网管理系统

> **难度** ★★★　|　**主控** ESP32-S3　|　**状态** ⬜ 未开始

手机/网页远程控制家电，设备状态实时同步，环境监测与自动化场景设置，支持多设备管理。

**技术栈**：ESP-IDF / Arduino、MQTT、后端服务、Web 前端

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| 继电器模块 | 家电开关控制 |
| DHT11 | 温湿度采集 |
| 光敏电阻模块 | 光照检测 |
| 触摸模块 | 本地触摸控制 |
| 0.96" OLED | 本地状态显示 |

## 功能需求

- [ ] 手机或 Web 控制家电
- [ ] 设备状态实时同步
- [ ] 环境数据监测
- [ ] 自动化场景设置
- [ ] 手动与自动控制
- [ ] 多设备管理

## 技术要点

- 设备模型与状态同步机制
- 简单场景规则引擎（IF 条件 THEN 动作）
- 本地控制与远程控制的优先级处理

## 拓展方向

- 接入语音助手，或做小程序端控制界面
