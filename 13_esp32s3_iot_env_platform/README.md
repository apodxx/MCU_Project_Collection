# 13 · 基于 ESP32-S3 的物联网智能环境监测平台

> **难度** ★★★　|　**主控** ESP32-S3　|　**状态** ⬜ 未开始

设备采集环境数据经 MQTT 上云，Web 端实时监控、历史曲线、阈值配置与异常事件记录。

**技术栈**：ESP-IDF / Arduino、MQTT、Spring Boot、Vue 3、MySQL

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| DHT11 | 温湿度采集 |
| MQ 气体传感器 | 气体检测 |
| 光敏电阻模块 | 光照检测 |
| 0.96" OLED | 设备端本地显示 |
| Wi-Fi（板载） | 数据上传通道 |

## 功能需求

- [ ] 实时环境数据采集
- [ ] Wi-Fi 数据上传
- [ ] Web 实时监控
- [ ] 历史数据曲线
- [ ] 报警阈值配置
- [ ] 异常事件记录

## 技术要点

- MQTT 主题与消息格式设计
- 后端 REST API + 数据库表设计
- 前端实时刷新与图表展示

## 拓展方向

- 增加设备管理与多设备接入，升级为项目 14 的完整 IoT 系统

## 备注

全栈项目，工作量最大，建议先完成项目 12 作为通信与报警的铺垫。
