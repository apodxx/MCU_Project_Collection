# 06 · 基于 STM32 的多功能电子数据采集终端

> **难度** ★　|　**主控** STM32F103C8T6　|　**状态** ⬜ 未开始

多路传感器轮询采集、OLED 多页面显示、参数可设、超限报警，并通过串口输出数据。

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| DHT11 | 温湿度采集 |
| 光敏电阻模块 | 光照采集 |
| MQ 气体传感器 | 烟雾 / 可燃气体检测 |
| 0.96" OLED | 多页面显示 |
| 旋转编码器 | 参数设置 / 翻页 |

## 功能需求

- [ ] 多种传感器数据采集
- [ ] OLED 多页面显示
- [ ] 参数设置
- [ ] 超限报警
- [ ] 串口输出数据

## 技术要点

- 时间片轮询调度多路采集
- 页面 / 菜单框架与按键状态机
- 串口帧协议（帧头 + 数据 + 校验）

## 拓展方向

- 增加 W25QXX 做历史数据记录，升级为小型数据记录仪
