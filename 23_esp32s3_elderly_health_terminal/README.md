# 23 · 基于 ESP32-S3 的智能老人健康数据采集与管理终端

> **难度** ★★★★　|　**主控** ESP32-S3　|　**状态** ⬜ 未开始

健康数据录入、本地显示与存储，Wi-Fi 上传，多用户管理与历史记录查询、异常提醒。

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| 0.96" OLED | 数据录入与显示界面 |
| 蜂鸣器 | 异常数据提醒 |
| W25QXX | 健康数据存储 |
| 红色生物传感器（可选） | 心率 / 血氧采集，型号待确认 |

## 功能需求

- [ ] 健康数据录入
- [ ] 数据本地显示
- [ ] 数据存储
- [ ] Wi-Fi 上传
- [ ] 多用户数据管理
- [ ] 历史记录查询
- [ ] 异常数据提醒

## 技术要点

- 数据采集与录入交互
- 多用户数据管理与存储结构
- 设备通信与用户身份关联

## 研究内容

- 数据管理
