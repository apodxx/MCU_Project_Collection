# 20 · 基于 ESP32-S3 的多传感器融合环境异常识别系统

> **难度** ★★★★　|　**主控** ESP32-S3　|　**状态** ⬜ 未开始

多传感器同步采集与滤波，用加权评分和规则判断做环境状态分类与异常等级划分。

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| DHT11 | 温湿度采集 |
| MQ 气体传感器 | 气体检测 |
| 光敏电阻模块 | 光照检测 |
| 麦克风模块 | 声音检测 |
| MPU6050 | 振动 / 姿态检测 |
| 0.96" OLED | 综合状态显示 |

## 功能需求

- [ ] 多传感器同步采集
- [ ] 传感器数据滤波
- [ ] 多参数联合判断
- [ ] 环境状态分类
- [ ] 异常等级划分
- [ ] Wi-Fi 远程监控
- [ ] 异常记录保存

## 技术要点

- 多传感器数据融合与归一化
- 加权评分模型
- 规则判断与等级划分

## 研究内容

- 多传感器数据融合
- 阈值算法
- 加权评分算法
- 规则判断算法

## 备注

重点不是单传感器越限报警，而是综合环境状态与其他传感器数据做联合判断。
