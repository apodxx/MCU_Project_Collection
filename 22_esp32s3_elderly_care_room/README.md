# 22 · 基于 ESP32-S3 的智能养老居室监护系统

> **难度** ★★★★★　|　**主控** ESP32-S3　|　**状态** ⬜ 未开始

居室温湿度、气体、光照、姿态多参联合监测，安全评分与分级报警，本地显示 + 远程管理。

## 硬件清单

| 模块 | 说明 |
| :-- | :-- |
| DHT11 | 居室温湿度 |
| MQ 气体传感器 | 环境气体检测 |
| MPU6050 | 设备姿态 / 活动检测 |
| 光敏电阻模块 | 夜间光照监测 |
| 0.96" OLED | 本地信息显示 |
| 蜂鸣器 | 异常声光报警 |
| W25QXX | 报警记录存储 |

## 功能需求

- [ ] 居室温湿度监测
- [ ] 环境气体检测
- [ ] 夜间光照监测
- [ ] 设备姿态异常检测
- [ ] 活动异常提醒
- [ ] OLED 本地显示
- [ ] 异常声光报警
- [ ] Wi-Fi 远程数据上传
- [ ] Web 端健康与环境数据管理
- [ ] 历史报警记录查询

## 技术要点

- 多传感器联合监测与数据融合
- 居室环境安全评分模型
- 分级报警与本地 / 远程双通道

## 创新点
